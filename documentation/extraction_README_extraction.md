# Complete M2: extraction and aggregate descriptions

`01_extract_complete_M2.R` creates the new main Table 3 and supplementary
Tables S22–S29 (S28 and S29 have estimator-specific panels). It reads existing
models; it does not refit SEMs or predictive models. The original 24 tables
remain generated by the previous table package.

Run in a fresh session:

```sh
Rscript --vanilla 01_extract_complete_M2.R /path/to/private/project /path/to/output /optional/path/to/02_S7_S8_caminos_numericos_IC_Holm18.csv
```

Packages: `lavaan`, `haven`, `jsonlite`, and `digest`. The optional environment
variable `M2_R_LIBRARY` points to an already installed R library. No packages
are installed automatically. The project-relative library path is used if it
exists. See `sessionInfo.txt` and `environment.json` for the verified run.

## Private inputs

Paths and SHA-256 hashes are listed in `input_manifest.csv`. These inputs are
not distributed by this extraction folder:

- `datos_originales/Base_Final.sav`;
- the canonical `analytic_data.rds`;
- `SEM_items_MLR.rds` and `SEM_items_WLSMV.rds`;
- four M2 CFA/SEM fitted objects, one of each with MLR and WLSMV;
- the historical two indirect-effect CSV files (for an extraction-rule check).

An optional CSV from the previous table package verifies exact correspondence
with the old S7/S8 coefficients, intervals, and Holm18 decisions. If it is not
supplied, this check is explicitly `NOT_CHECKED`, not passed.

## Output map

`tables_manifest.json` lists each panel's caption, notes, CSV, model, estimator,
sample, source path, script, and recommended page orientation. Formatted CSV
files have a single header row and no row-number column. Reading them with
`header=FALSE` retains the first row as the table's printed header.

- T3: all six predictors by PP1/PP2/PP3, with beta, own 95% CI, and Holm18 stars.
- S22: aggregate descriptors by institution and overall, with denominators.
- S23–S26: all 24 loadings for each separate M2 CFA/SEM and MLR/WLSMV fit.
- S27: model-implied total and conditional disturbance correlations separately.
- S28A/B: 21 focal and 49 control regression coefficients per estimator.
- S29A/B: all 16 model-defined indirect products/sums per estimator.

Complete numeric CSVs also retain b, beta, their respective standard errors
and confidence intervals, and raw p values. No individual participant rows
are written. `fit_data_source_checks.csv` compares the actual data stored in
all six fitted objects against the canonical analytic data; country indicators
are reconstructed only to verify the original coding. All differences are zero.

## Multiplicity and interpretation

The 18-path item family and 21-path focal latent-PSB family use p values of
unstandardized coefficients. The historical **16-indirect family instead uses
p values from the standardized solution**. The script preserves that original
rule; it does not generalize the regression rule to indirect effects. A separate
audit computes b-based Holm16. The two rules change no p<.05 decision here:
MLR supports 2/16 effects under either rule; WLSMV supports 6/16.

The largest absolute differences in adjusted p values are 0.02207442 (MLR)
and 0.00605403 (WLSMV). See `S29_*_historical_rule_comparison.csv`.

All intervals are pointwise, not simultaneous. CFA total factor correlations
have intervals extracted from their matching standardized covariance parameter.
SEM total factor correlations are point estimates; their intervals were not
estimated. Disturbance correlations are distinct and include zero constraints
for PSB. Fixed unstandardized marker loadings are explicitly marked fixed,
while their standardized estimates retain the available confidence interval.
Indirect products from cross-sectional data are not causal mediation effects.
One institution per country prevents separation of institutional from national
effects. The final artifact is an extraction package; complete refitting still
requires authorized access to the private inputs and original analysis scripts.
